# carniere

A small web app (installable PWA) for recreational fishermen: pick a spot on a map or use the GPS, see seabed depth (EMODnet) and sea marks (OpenSeaMap), get an activity estimate for the next 12 hours (daylight, solunar periods, tide speed, pressure, wind), and log your catches, which the app uses to refine its advice over time. Catches can optionally be shared with a community (Supabase backend, schema in `supabase.sql`). The interface is in Italian.
